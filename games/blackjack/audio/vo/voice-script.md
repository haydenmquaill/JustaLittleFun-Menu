# Blackjack HOST — Dealer Voice Line Script

Three **distinct** takes per line (one is chosen at random each play). File each take
under the matching manifest path, e.g. `audio/vo/classic/total/17/1.mp3`.

Line-key → folder reference:

| Key | Folder |
|---|---|
| placeYourBets | `place_your_bets/` |
| betsClosed | `bets_closed/` |
| dealersTurn | `dealers_turn/` |
| playerBlackjack | `player_blackjack/` |
| playerBust | `player_bust/` |
| dealerBlackjack | `dealer_blackjack/` |
| dealerBust | `dealer_bust/` |
| dealerWin | `dealer_win/` |
| dealerLose | `dealer_lose/` |
| dealerPartial | `dealer_partial/` |
| pushAll | `push_all/` |
| pushWinner | `push_winner/` |
| pushLoser | `push_loser/` |
| pushMixed | `push_mixed/` |
| winner | `winner/` |
| signoff | `signoff/` |
| total_4 … total_21 | `total/4/` … `total/21/` |

Each cell below is take **1 / 2 / 3**.
